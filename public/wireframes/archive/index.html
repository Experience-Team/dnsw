How to restore one

Restoring copies a snapshot back over the working files, on a branch, so it goes through a pull request like any other change. The archive itself stays as it is.

  1. Start a branch from the latest main: 
    git switch -c restore-v1-2026-11-26 origin/main
  2. Copy the snapshot back (use 2026-11-26/v2 for Version 2). Add --dry-run first to see what would change: 
    npm run archive:restore -- 2026-11-26/v1
  3. Check git diff --stat, then open both versions in the viewer. Shared files (shared.css, themes/hifi.css, pv-device.js, concepts-*.js, the data and pictures) come back too, so the other version can change as well.
  4. Commit and open a pull request.

Without the script

Copy every file listed under files in the snapshot's archive.json from public/wireframes/archive/<date>/<version>/ to public/wireframes/, at the same path. In each copied .html file, delete the block from <!-- archive:start to <!-- archive:end --> (it keeps the archive's saved state apart). Don't copy the snapshot's prototype-pick-your-team.html (a viewer cut down to one version) or archive.json. Files added since the snapshot are left as they are.
