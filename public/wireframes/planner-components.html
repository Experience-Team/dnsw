Map placeholder .pl-map

Grey box with an X and a label, plus a plain list beside it. Trip map for the whole stay, day map for each day.

Desktop: trip map

Desktop: day map

Mobile, 375px: day map

  1. 1Trip map: the whole stay across both cities, with days and the drive between them listed beside it.
  2. 2Day map: stops numbered in the same order as that day's timeline, with travel time between each.
  3. 3Pins use the listing's address.geo (live). Travel legs need the same routing source as the option card.
  4. 4Mobile: the map sits above the stop list, so it's always visible. The plan view screen can decide whether it moves behind a single tap.

  2. 2Matches and interests open a checklist, so the fan can pick several. Team and match lists come from the match schedule (not in contract, same question as the match block).
