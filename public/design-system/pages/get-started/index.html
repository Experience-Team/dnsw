Who it is for

Designers use it to check a value, a component's states or a rule before designing, and to hand over work that is already built from the system's parts.

Developers use it to find the token or class to use, see the component live in each brand, and check the behaviour rules before a change is handed over.

Code is the source of truth

The values live in CSS. These pages fetch that CSS and read it, so if a value changes in the code it changes here on the next load. If something here looks wrong, the code is wrong, and the fix goes in the code.

Figma follows code: tokens are pushed from the CSS to Figma variables, not the other way round.

What it covers

  • Foundations: principles, accessibility, layout, interaction, content and data rules.
  • Styles: colour, type, spacing, shape, elevation, motion and icons.
  • Components: building blocks with live examples.
  • Patterns: components working together on a recurring job.
  • Brands: what each brand sets and who owns it.
