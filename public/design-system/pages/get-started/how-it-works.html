Three layers of tokens

LayerWhat it isExampleSet by
PaletteA brand's raw values, with no meaning attached.--tth-color-orange: #ff4802Each brand
RolesWhat a value is for. The names are shared; each brand points them at its palette.--c-accent, --c-ink-2, --space-4Names: the system. Values: each brand.
ComponentA setting for one component, only where a role is not enough.--radius-card, --add-nudgeThe system, pointed at roles

Components only ever use roles and component tokens. That is what lets one component work in every brand.

Three tiers of components

TierWhat belongsExamples
CoreBrand-neutral building blocks any site could use.Buttons, chips, tags, toast, sheets, date picker
PatternsCore components solving a recurring job together.Choosing several things, confirming a change, saving without an account
Project modulesBuilt for one project from core parts, and kept with that project.The Third Half's team card fan, timeline bar, Where to watch

When a second project needs a project module, it moves down into core: its project-specific details become tokens or options. See contributing.

Brands are separate from projects

A brand is a set of values; a project is what is built. The Third Half is a DNSW brand used by the Rugby World Cup planner, and could be used by other DNSW work. Marks that belong to event partners (for example World Rugby's Rugby World Cup marks) are artwork, not tokens, and are kept out of the brand files.
