The contract is the source of truth

docs/product-data-contract.md lists every product page field. Do not invent fields. If a design needs one that is not in the contract, stop and ask.

Field status

StatusMeaningHow to build
liveIn live data today.Build against it.
gapNot in live data.Render from fixtures only, with the pink marker in wireframes, and define the empty state.
unverifiedNot confirmed.Do not build against it until confirmed.

Every module defines its empty state

For each field a module uses, say what shows when it is missing: hide the line, show a fallback, or hide the module. Write it in the module's annotation, not only in the design.

"No opening hours: the line is hidden and the card still shows the price and distance."

Leave the empty state to whoever builds it.

Realistic data

Use real data when it is available. When it is not, ask before making it up. Opening hours, prices, travel times, testimonials and usage numbers are never invented.
