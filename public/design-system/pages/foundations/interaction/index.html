These rules come from things reviewers had to point out in the prototypes. Every prototype change is checked against all of them before it is handed over.

The checks

  1. Movement can be followed. See movement.
  2. Choices behave like what they mean. See choosing several things.
  3. Every multi-select can be cleared. See choosing several things.
  4. Walk every combination before handing over. Pick, unpick, mix, clear, change your mind, reload, keyboard only and reduced motion, from every place a control appears and in every starting state. Press it twice. Make several changes in a row and check every summary describes the latest.
  5. The movement that matters is obvious. See movement.
  6. Content fits its window. See layout.
  7. Patterns go everywhere they apply. When one instance of a component or cue changes, list every place it appears, agree the scope, then change them all in one pass.
  8. The page only moves when people expect it to. See page movement and focus.
  9. Check the build against the whole brief. Say what is done, what is deliberately not done and why, and what is next.
  10. One rule for more detail inside a sheet. See sheets.
  11. A change that lands out of view is confirmed where the person is. See toast and confirming a change.
  12. Say what else a change will touch, before building. Trace shared behaviour to everywhere it shows up, the docs included.
