Start here

The design system is the single place to find what DNSW pages and prototypes are made of: the values (tokens), the parts (components), the rules for how they behave, and the brands they can wear. Every value on these pages is read from the CSS the wireframes and prototypes already use, so the docs and the build cannot disagree.

What makes it scale

Components never use a raw colour or size. They use roles, such as --c-ink for body text or --c-accent for a selected state. A brand is a file that sets those roles. A new site or campaign is therefore one new brand file, and every component works in it on day one.
