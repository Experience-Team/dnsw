How brands work

A brand is one CSS file. It defines its palette, then points the shared roles at it. Everything a brand does not set comes from the Wireframe base, so a new brand can start small and grow.

/* themes/my-brand.css */
:root[data-theme="my-brand"] .cn-phone {
  --mb-color-sea: #0a5c7a;          /* palette */
  --c-accent: var(--mb-color-sea);  /* role */
  --c-btn: var(--mb-color-sea);
}

Ownership

Sydney.com, Visit NSW and The Third Half are DNSW brands. Event partners' marks, such as World Rugby's Rugby World Cup marks, are artwork used under licence; they are not brand tokens and are not stored in brand files.
