The prototype icon set, read from window.tpIcons in public/wireframes/concepts-teams.js. Icons draw in the text colour.

Using icons

  • Icons support a label; they rarely replace one. An icon-only button needs an aria-label.
  • Add, Added and Remove are outline circles in the text colour. Added is the same button pressed, not a different button.
  • The calendar icon goes on every button that sets or changes dates. The card-fan icon goes on every Pick your teams prompt.
  • Mark icons aria-hidden="true" when a label is present.
